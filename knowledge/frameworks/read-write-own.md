# Read / Write / Own

## Origin
Chris Dixon, *Read Write Own* (2024). The canonical framing of crypto's place in internet history.

## The three eras

1. **Read (1990s)** — The early web. Static pages. Information access. Value capture: small, distributed (lots of websites).
2. **Read-Write (2000s-2010s)** — Web 2.0. User-generated content, social media, mobile. Users could create, but platforms captured the value (Facebook, Google, YouTube extract from creators).
3. **Read-Write-Own (now)** — Crypto / web3 enables user ownership of digital property, identity, value flows. Tokens, NFTs, onchain identity. Value can route back to users and builders.

## Why it matters
- It's a worldview-level frame: crypto isn't a sector, it's the next era of the internet.
- Pattern-matches crypto to PC (1977-1990s) and internet (1990s-2010s) — each began as a toy, was dismissed, then became foundational.
- Justifies multi-decade patient capital deployment through bear markets.

## How to apply it
- For crypto pitches: "Where does this fit in the Read-Write-Own framing?" — pure-financial-speculation projects don't.
- For consumer/social pitches: "What's the user-ownership story?" — increasingly relevant beyond crypto-native.
- For platform / protocol design: ownership primitives matter long-term; centralized rent extraction is structurally fragile.

## Related Dixon concepts
- **Protocols > Platforms** — open neutral protocols outcompete closed extractive platforms over long arcs.
- **Composability is a force multiplier** — onchain protocols compose like Lego.
- **Attract / Extract Cycle** — centralized platforms attract creators, then extract. Crypto solves this with credible commitments via code.

## Limitations
- Most "ownership" claims in crypto are still speculative; real user-ownership use cases beyond financial are still emerging.
- The three-era framing is elegant but may oversimplify — many overlapping waves at once.
