# GitHub

## What it does
Code hosting + collaboration platform built on Git. Where most of the world's open-source software lives. Acquired by Microsoft in 2018 for $7.5B.

## Stage when a16z entered
Series A (~2012). a16z led the round and Marc Andreessen joined the board.

## Lead partner from a16z
Marc Andreessen (board, founding-era champion).

## Thesis bucket it fits
- **Primary:** [[enterprise-infrastructure]] (dev tools).
- **Secondary:** Strong cultural-artifact value — represents the firm's belief in developer-first GTM.

## Why a16z backed it
1. **Developers as the new enterprise buyer** — pre-empting the trend that developers would drive software purchasing decisions, not CIOs.
2. **Open source as community infrastructure** — GitHub was the social layer of OSS; whoever owned that owned dev mindshare.
3. **Strong founders** — Tom Preston-Werner, Chris Wanstrath, P.J. Hyett, Scott Chacon — distinct, opinionated, builder energy.

## Trajectory
- Acquired by Microsoft (2018) — $7.5B at the time, a then-record enterprise software acquisition.
- Under Microsoft: integrated with VS Code, launched Copilot (2021) — became the canonical AI-coding product.
- Microsoft did not destroy the OSS culture, contrary to fears. GitHub remained vibrant.

## Lessons / pattern it sets
1. **Developer-first GTM** as a thesis driver — informs Stripe, Vercel, MongoDB, and dozens of subsequent a16z bets.
2. **Acquisition isn't always a failure** — for the right strategic fit, $7.5B is a clean win.
3. **Cultural moats matter** — GitHub had a vibe; that was part of the moat.
