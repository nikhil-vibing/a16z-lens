# Databricks

## What it does
Unified data + AI platform. Built on Apache Spark (founders are the Spark creators from UC Berkeley AMPLab). Provides data engineering, data warehousing (via Delta Lake), machine learning infrastructure, and increasingly a foundation-model layer (MosaicML acquisition).

## Stage when a16z entered
Multiple late-stage rounds; a16z is one of the largest investors. Ben Horowitz on the board.

## Lead partner from a16z
- Ben Horowitz (board).
- Martin Casado (infra thesis support).

## Thesis bucket it fits
- **Primary:** [[enterprise-infrastructure]] (data layer).
- **Secondary:** [[ai-infrastructure]] (post-MosaicML acquisition, increasingly AI-native).

## Why a16z backed it
1. **Founders are Apache Spark creators** — Matei Zaharia, Ali Ghodsi, Ion Stoica — academic + technical pedigree at the highest level.
2. **OSS-led, monetization clear** — Spark drove adoption; Databricks (managed Spark, then Delta Lake, then MLflow) monetized via cloud-hosted product. Textbook Casado "OSS is distribution" model.
3. **Massive TAM in data infrastructure** — competes with Snowflake; both can win as the modern data stack consolidates.
4. **AI-pivot strategic** — MosaicML acquisition + Mosaic AI positioning made Databricks more than a data platform.

## Trajectory / current state
- Valued at $62B in latest rounds (Series J, late 2024).
- $2B+ ARR, growing fast.
- Major competitor to Snowflake; both companies are likely IPO-bound.
- Strategically positioned for enterprise AI deployment — own the data, own the model layer adjacent.

## Lessons / pattern it sets
1. **Academic founder + OSS + cloud monetization** is a repeatable pattern. Casado's playbook in action.
2. **Acquisitions can sharpen thesis** — MosaicML moved Databricks from data infra to AI infra.
3. **Compete with bigger incumbents head-on** — Snowflake had a 5-year head start; Databricks closed the gap via product + market shift.
4. **Founder-CEO transitions can work** — Ali Ghodsi took over from Ion Stoica; smooth transition, no founder drama.
